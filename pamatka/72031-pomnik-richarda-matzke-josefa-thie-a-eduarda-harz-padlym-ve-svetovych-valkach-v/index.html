Pomník Richarda Mätzke, Josefa Thie a Eduarda Harz padlým ve světových válkách v Máslojedech

Pomník padlým · okres Hradec Králové › Máslojedy › Máslojedy

Pískovcová typová pyramida věnovaná 3 pruským vojákům, a to Richardu Mätzkemu od 2. dragounského pluku, Eduardu Harzovi od 3. gardového hulánského pluku a Josefu Thieovi od gardových myslivců. Pomník původně stával u silnice
Číslo dle komitétu 102. Pomník nese následující nápisy: "Hier ruht / Richard / MÄTZKE, / kgl. preuss / Soldat im / 2. Drag.-Reg. / gest. 18 5/8 66. / Jesus spricht: / Ich bin die Aufer / stehung u. das Leben." "Hier ruht / Josef / THIE / kgl. preuss. / Garde – / Jäger / gest. 18 6/8 66". "Hier ruht / Eduard / HARZ / kgl. preuss. / Soldat im / 3. Garde – / Ulanen - Reg. / gest 18 3/8 66." "Zde / odpočívají / tři pruští / vojínové. / Ježíš řekl / Já jsem / vzkříšení i život."
